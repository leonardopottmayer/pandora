# Databases Module

> User-built databases: bases, tables, typed fields, relations, queries, import and export.
> **Language:** English is the primary documentation. 🇧🇷 [Versão em português](pt-BR/README.md).

The **Databases** module lets each user build a small database of their own inside Pandora: bases with
tables, fields of types Pandora offers, records, relations between tables, saved views with filters,
and import/export to CSV and Excel. Field types, query operators, file formats and view layouts are all
extension points.

**Status:** design approved (2026-11-07); nothing built yet. Delivery runs in steps T1–T6.
