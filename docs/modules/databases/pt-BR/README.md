# Módulo Databases

> Bancos de dados montados pelo usuário: bases, tabelas, campos tipados, relações, consultas, import e export.
> **Idioma:** o inglês é a documentação primária. 🇺🇸 [English version](../README.md).

O módulo **Databases** deixa cada usuário montar um pequeno banco de dados próprio dentro do Pandora:
bases com tabelas, campos dos tipos que o Pandora oferece, registros, relações entre tabelas, visões
salvas com filtros e import/export para CSV e Excel. Tipos de campo, operadores de consulta, formatos de
arquivo e layouts de visão são todos pontos de extensão.

**Status:** design aprovado (2026-11-07); nada construído ainda. A entrega segue as etapas T1–T6.
