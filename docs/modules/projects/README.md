# Projects Module

> Work tracking: projects, custom item types and workflows, backlogs, sprints and boards with nested columns.
> **Language:** English is the primary documentation. 🇧🇷 [Versão em português](pt-BR/README.md).

The **Projects** module is a work tracker in the spirit of Azure Boards and Jira. Each project has its own
process (item types, custom fields, workflows with state categories, backlog levels), copied from a
template and editable; epics, features, stories, tasks, bugs and custom types; backlogs ordered by rank;
sprints with capacity; and kanban and sprint boards whose columns form a tree of groups and sub-columns
mapped to states. One user for now, with the membership model in place from day one.

**Status:** design recorded (2026-11-07); nothing built yet. Delivery runs in steps P1–P7.
