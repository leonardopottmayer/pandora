# Módulo Projects

> Gestão de trabalho: projetos, tipos de item e workflows customizados, backlogs, sprints e boards com colunas aninhadas.
> **Idioma:** o inglês é a documentação primária. 🇺🇸 [English version](../README.md).

O módulo **Projects** é um gerenciador de trabalho no espírito do Azure Boards e do Jira. Cada projeto tem
o próprio processo (tipos de item, campos customizados, workflows com categorias de estado, níveis do
backlog), copiado de um template e editável; epics, features, stories, tasks, bugs e tipos customizados;
backlogs ordenados por rank; sprints com capacidade; e boards kanban e da sprint cujas colunas formam uma
árvore de grupos e subcolunas ligadas a estados. Um usuário por enquanto, com o modelo de associação
pronto desde o início.

**Status:** design registrado (2026-11-07); nada construído ainda. A entrega segue as etapas P1–P7.
