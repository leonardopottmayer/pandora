# Radar Module

> A curated tech digest: followed sources, AI relevance scores, and a daily or weekly digest.
> **Language:** English is the primary documentation. 🇧🇷 [Versão em português](pt-BR/README.md).

The **Radar** module follows the tech sources the user picks (YouTube channels, Medium, Reddit, Hacker
News, blogs, GitHub releases, newsletters from Communications). An AI model scores and summarizes each
new item against the user's interest profile and 👍/👎 feedback, and the best items go out as a digest
through Channels and show up in a feed screen. Source connectors, the scorer and the digest are
extension points.

**Status:** design recorded (2026-11-07); nothing built yet. Delivery runs in steps R1–R5.
