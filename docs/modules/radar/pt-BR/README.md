# Módulo Radar

> Um digest de tecnologia com curadoria: fontes seguidas, notas de relevância por IA e um digest diário ou semanal.
> **Idioma:** o inglês é a documentação primária. 🇺🇸 [English version](../README.md).

O módulo **Radar** acompanha as fontes de tecnologia que o usuário escolhe (canais do YouTube, Medium,
Reddit, Hacker News, blogs, releases do GitHub, newsletters do Communications). Um modelo de IA dá nota e
resume cada item novo de acordo com o perfil de interesse e o feedback 👍/👎 do usuário, e os melhores
itens saem como um digest pelo Channels e aparecem numa tela de feed. Os conectores de fonte, o avaliador
e o digest são pontos de extensão.

**Status:** design registrado (2026-11-07); nada construído ainda. A entrega segue as etapas R1–R5.
